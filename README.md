# Wisnu - Portfolio Website

A personal portfolio website showcasing my work as a Data Engineer & Analyst.

## Features

- 🌓 Dark/Light mode toggle
- 📱 Fully responsive design
- 🎨 Clean, modern UI
- 🔄 Smooth scroll animations
- 🏷️ Project filtering by category
- ⚡ Fast and lightweight

## Technologies

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Inter)

## Sections

- **Hero** - Introduction with profile and social links
- **About** - Background and experience stats
- **Skills** - Technical skills organized by category
- **Projects** - Featured projects with live demo links
- **Contact** - Contact information and social links

## Deployment

This site is configured for deployment on Vercel or Netlify.

### Vercel
Simply connect your GitHub repository to Vercel for automatic deployments.

### Netlify
Connect your repository or drag and drop the project folder.

## Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local server: `npx serve .`
